// the core idea

A file is a list of bytes. A video frame is a grid of pixels. Every 4 bytes of your file become exactly one pixel.

48656C6C
4 bytes = 32 bits

// encoding

1Read the file as raw bytes.
2Add a header: format tag, length, checksum, filename.
3Group the bytes in fours, one pixel each.
4Fill frames row by row. 1280 x 720 holds about 3.5 MB.
5Pad the last frame and join all frames into a lossless video.

// decoding

1Read every frame's pixels back into bytes.
2Read the header for the real length and filename.
3Remove the padding and check the checksum.
4Rebuild the original file.

// why lossless

Normal video compression changes pixel values, which would corrupt the file. PixelVault writes a lossless video, so every bit comes back exactly.
